What we do

Advice about data analyst careers is mostly opinion. We wanted evidence from the market itself.

The question

Which skills matter most for Data Analyst jobs in India right now, and which ones go with higher advertised pay?

Our approach

We built our own pipeline: live postings from an official jobs API, a SQL database, careful cleaning, then regression and clustering.

Why it matters

Job seekers can spend their learning time on the skills that actually open doors and lift pay, not on guesses.

How it works

Five steps from raw job ads to the charts on this site. Every decision is logged, with its reasoning.

  1. 1

    Collect

    Weekly runs pull every open analyst posting in India from the Adzuna API and public company job boards.

    Python, GitHub Actions
  2. 2

    Store

    Raw snapshots are saved untouched, then loaded into a SQL database that tracks each posting over time.

    SQLite, SQL
  3. 3

    Clean

    Salaries in consistent units, experience levels, cities, and one name per company.

    pandas
  4. 4

    Analyse

    Skill demand, a salary regression at the same experience and city, and clustering into job types.

    statsmodels, scikit-learn
  5. 5

    Present

    This website: interactive charts built from aggregated results only.

    HTML, JavaScript, ECharts
